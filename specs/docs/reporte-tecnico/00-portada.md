## Descripción del Documento

Este reporte recopila la especificación técnica, el modelo de datos real, la arquitectura física y lógica, la descripción detallada de interfaces gráficas y los tópicos de mensajería implementados para el funcionamiento del sistema SafeAir. 

SafeAir es un sistema de monitoreo, persistencia y control ambiental mediante emuladores, API REST, MQTT y PostgreSQL. Este documento sirve de base para la auditoría de diseño del sistema, demostrando la integración de protocolos de comunicación web (REST API), protocolos de mensajería para el Internet de las Cosas (MQTT), persistencia de datos relacionales en red local, simulación de hardware mediante emuladores en lenguaje Java y el uso de contenedores Docker para la portabilidad y despliegue del entorno educativo.
